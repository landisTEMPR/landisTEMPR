## Projects

**[Atomic-Structure-Simulation](https://github.com/landisTEMPR/Atomic-Structure-Simulation)** · `C` `OpenGL` `Vulkan`  
Real-time 3D atom simulation — dynamic electron orbit rendering, nucleus detail, built from scratch. An ongoing exploration of graphics pipelines and physics-based rendering. *(active)*

**[MIPS-AssemblyLangInterpreter](https://github.com/landisTEMPR/MIPS-AssemblyLangInterpreter)** · `C++` `Assembly`  
Full MIPS-I ISA interpreter with a dynamic terminal interface. Supports interactive mode, manual instruction entry, and step-by-step debugging. Built to actually understand what's happening at the hardware level. *(active)*

**[SiegeScope-Client](https://github.com/landisTEMPR/SiegeScope-Client)** · `Go` `Fyne` `SQLite`  
Cross-platform Rainbow Six: Siege replay tracker. Parses `.rec` files, persists match history with SQLite, and surfaces win rates, operator stats, and round-by-round breakdowns.

**[2D-Particle-Simulation](https://github.com/landisTEMPR/2D-Particle-Simulation)** · `C++`  
Interactive 2D particle physics — force models, collision resolution, real-time rendering. Started as curiosity about how things move.

**[Mini-Projects](https://github.com/landisTEMPR/Mini-Projects)** · `C++`  
Scratchpad for experiments and quick builds. Where ideas get tested before becoming real projects.
